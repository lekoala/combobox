@lekoala/combobox × data-grid

data-grid-component is untouched: it renders its header filter row and keeps listening to its native <select> by delegation. A tiny enhancer wraps each select filter (data-filter-mode="select") in a <combo-box> and lets the grid reopen... nothing: the native change the combobox dispatches on the source select is all data-grid needs. No plugin, no adapter, no data-grid changes.

Local grid, select filters enhanced

Wiring on the public headerRendered hook only. DataGrid guarantees an empty value="" option — hence allow-empty-option. search="includes" makes the doctor/country lists type-filterable. The boolean Active column keeps its native tri-state select, so an enhanced and an untouched filter sit side by side in the same row.

function enhanceSelectFilters(grid) { for (const select of grid.querySelectorAll( '.dg-head-filters select.dg-filter-control[data-filter-mode="select"]' )) { if (select.parentElement?.localName === "combo-box") continue; const field = select.closest(".dg-select-field"); const box = document.createElement("combo-box"); box.setAttribute("search", "includes"); box.setAttribute("allow-empty-option", ""); box.setAttribute("placeholder", "Filter…"); select.before(box); box.append(select); field?.classList.add("dg-has-combobox"); } } grid.addEventListener("headerRendered", () => enhanceSelectFilters(grid));
